# Privacy Policy — Roblox Server Suite

**Last updated: April 6, 2026**

Roblox Server Suite does not collect, store, or transmit any personal user data.

- All preferences (server size preference, UI settings) are stored locally on your 
  device using the browser's built-in `chrome.storage.local` API.
- No data is ever sent to any external server owned or operated by this extension.
- Requests made to `roblox.com` APIs are made directly from your browser using your 
  existing Roblox session — no credentials or personal information are intercepted 
  or logged by this extension.

If you have questions, open an issue on this repository.
